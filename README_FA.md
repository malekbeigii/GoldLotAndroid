# ماشین‌حساب حجم و ریسک طلا – نسخه اندروید

این پروژه نسخه اندرویدی آفلاین فایل V6.html است. رابط کاربری و منطق محاسباتی HTML اصلی داخل WebView اجرا می‌شود؛ بنابراین محاسبات و ژورنال بدون اینترنت کار می‌کنند.

## سازگاری
- حداقل نسخه اندروید: Android 5.0 (API 21)
- نسخه هدف: Android 15 (API 35)
- برای نمایش صحیح، Android System WebView دستگاه باید فعال و به‌روز باشد. سازگاری با تمام نسخه‌های اندروید ممکن نیست؛ این پروژه از اندروید 5 به بالا را هدف می‌گیرد.

## ساخت APK
با Android Studio نسخه‌ای که از Android Gradle Plugin 8.7.3 پشتیبانی کند، پروژه را باز کنید و سپس از منوی Build گزینه Build APK(s) را بزنید. همچنین با JDK 17، Gradle 8.9 و Android SDK Platform 35 می‌توان اجرا کرد:

```bash
gradle assembleDebug
```

خروجی:
`app/build/outputs/apk/debug/app-debug.apk`

## ساخت خودکار در GitHub
پروژه را در یک مخزن GitHub قرار دهید. Workflow موجود در `.github/workflows/android.yml` با هر push به شاخه main یا با اجرای دستی، APK دیباگ می‌سازد. فایل APK در بخش Actions همان اجرای Workflow، قسمت Artifacts قابل دریافت است.

## نکات
- تنظیمات و ژورنال در حافظه محلی WebView ذخیره می‌شوند.
- دانلود پشتیبان JSON و CSV از طریق انتخاب‌گر ذخیره فایل اندروید انجام می‌شود.
- بازیابی پشتیبان از طریق انتخاب فایل اندروید پشتیبانی می‌شود.
- داده‌ها روی دستگاه می‌مانند؛ حذف داده برنامه یا پاک‌کردن فضای ذخیره‌سازی برنامه ممکن است آن‌ها را حذف کند. از پشتیبان‌گیری دوره‌ای استفاده کنید.
- این نسخه با امضای debug ساخته می‌شود و برای انتشار عمومی در Google Play باید کلید امضای release جداگانه تنظیم شود.
